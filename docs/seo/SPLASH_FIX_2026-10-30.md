# Однократная стартовая заставка

Исправлено повторное появление заставки при возврате на главную. Решение о показе принимается один раз при загрузке приложения и сохраняется в sessionStorage вкладки.

- Первое открытие главной в новой сессии вкладки: заставка показывается.
- «На главную», логотип, переходы между разделами и возврат браузером: повторного показа нет.
- Перезагрузка в той же сессии вкладки: повторного показа нет.
- Новая сессия вкладки: заставка снова разрешена.
- Если уйти в раздел во время анимации, она сразу скрывается и при быстром возврате не появляется заново.
- При первоначальном входе сразу в раздел последующий переход на главную не запускает заставку.

Для обычного закрытия вкладки и нового открытия сайта используется новая сессия sessionStorage. Восстановление вкладок средствами браузера может восстанавливать и их сессию; очистка данных браузера не выполняется. При недоступном sessionStorage повторный показ предотвращается в рамках текущего запуска приложения.

Удалена проверка performance navigation type reload: этот признак относится к загрузке документа и раньше повторно разрешал анимацию при клиентском возврате на главную. Эффект запуска анимации больше не зависит от текущего маршрута. Решение сохранено в ref, поэтому повтор эффектов React Strict Mode не отменяет единственный таймер скрытия.

Проверки: 17 frontend тестов успешны, включая четыре новых сценария для реальных эффектов Splash: первый вход и Strict Mode, быстрый возврат, перезагрузка и новая сессия, вход через раздел. Исходный компонент сохранён в splash-fix/Splash.before.tsx. Вычислительная логика, оформление заставки и её длительность не менялись.

Изменения выполняются в devcodex. Git add, commit, merge, push и деплой не выполнялись.
