## Различия локальной и публичной версии

Локальный API содержит 399 записей CRS, публичный — 394. Только локально присутствуют:

- UTM_WGS84;
- MSK:36:1 и MSK:36:2;
- MSK:17:UNVERIFIED и MSK:19:UNVERIFIED — служебные записи неподтверждённых вариантов.

На публичном сайте также не обнаружены UTM и МСК-36 в списке выбора. Точный коммит работающих контейнеров не устанавливался: разница списков доказывает различие возможностей, но не определяет SHA релиза. Данные: [environment.json](baseline-2026-10-30/environment.json), [публичный реестр](baseline-2026-10-30/crs.json).

До публикации текстов про UTM и МСК-36 необходимо проверить, что соответствующая версия конвертера действительно выпущена. Отсутствие этих систем на текущем публичном сайте не считать регрессией будущего SEO изменения без сравнения версий приложения.

deploy/README.md содержит устаревшее описание МСК и СК-63 как находящихся в разработке. Оно расходится с текущими реестрами и уже доступными публичными вариантами. VPS_DEPLOYMENT.MD описывает общий VPS; его конфигурация в этом блоке не менялась.

## Контрольные сценарии для следующих блоков

После изменения метаданных, текстов или структуры страницы повторять следующие проверки. Сравнивать одинаковые версии окружения и настройки систем координат.

| Проверка | Данные и критерий приёмки |
| --- | --- |
| Запуск и навигация | Главная → конвертер → закрытие; FAQ; мобильное меню; прокрутка возвращается после закрытия |
| Тождественный пересчёт | WGS84 56 / 12 → WGS84: 56 / 12 |
| ГК и порядок осей | WGS84 55,75 / 37,6 → ГК-СК-42, 6°, зона 7: X≈7412206,4362; Y≈6181717,1907; отклонение от снимка не более 0,01 м |
| UTM север | WGS84 56 / 12 → UTM 32 N: X≈687071,44; Y≈6210141,33; допуск 0,01 м |
| UTM юг | WGS84 −44 / 174 → UTM 59 S: X≈740526,32; Y≈5123750,87; допуск 0,01 м |
| Независимые зоны | Разные исходная и целевая зоны ГК/UTM не подменяют друг друга; автоматический и ручной режимы сохраняются |
| МСК и СК-63 | Повторить запросы msk50 и sk63 из conversion-reference.json; допустимое изменение координат для SEO задач — не более 0,01 м |
| Реверс | Поменять направление после пересчёта и получить исходные координаты в пределах допуска существующих тестов |
| Угловые форматы | 55°45′30″ / 37°30′00″ → 55,7583333333 / 37,5; сохраняются десятичная запятая, отрицательный угол и округление |
| Импорт Excel | Географические и плоские координаты, 100 строк; порядок lat/lon и X/Y, предел 100 строк, две колонки и сообщения ошибок |
| Каталог и ведомость | В обоих XLSX сохранены количество строк, порядок осей и значения; для UTM — зона и полушарие; числовые проверки уже покрыты backend-тестами |
| Неподтверждённые системы | Недоступны для выбора и отвергаются API; не появляются в SEO описаниях как поддерживаемые |
| HTTP после SEO изменений | Главная 200, неизвестный URL 404; robots и sitemap после их реализации 200; редиректы HTTP/www сохранены |

UTM проверяется локально и на публичном сайте после выпуска соответствующей версии. Числовой снимок шести локальных запросов и ответов: [conversion-reference.json](baseline-2026-10-30/conversion-reference.json). Это контроль сохранения поведения реализации; самостоятельной сертификацией точности он не является. UTM примеры также проверяются существующим тестом по опубликованным примерам PROJ.

Импорт и оба XLSX проверены локальными тестами обработчиков; загрузка и скачивание файлов через публичный браузер в этом блоке не выполнялись. Полный путь браузер → HTTP → файл нужно пройти перед выпуском, если будут затронуты элементы конвертера.
