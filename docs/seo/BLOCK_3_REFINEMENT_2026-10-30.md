# Общие темы и отдельные страницы GeoConverter

Доработка блока 3 выполнена локально 30 октября 2026 года. Новые блоки главной используют общие стили панелей. Конвертер, возможности, FAQ и поддержка открываются самостоятельными страницами; главная под ними отсутствует.

## Навигация

| Адрес | Содержимое |
| --- | --- |
| / | Стартовая страница с SEO содержанием |
| /converter | Конвертер координат |
| /features | Возможности |
| /faq | Полный FAQ |
| /support | Добровольная поддержка проекта |

Меню и кнопка запуска используют обычные ссылки Next.js. У разделов есть H1, собственные title, description и canonical; опубликованные адреса добавлены в sitemap. Кнопка «На главную», логотип и возврат браузером работают. Старые модальные обёртки и блокировка прокрутки при открытии разделов удалены; блокировка остаётся только у мобильного меню.

## Оформление

Главная использует общий класс card и переменные фона карточек; внутренние элементы используют те же светлые и тёмные поверхности, границы и текст, что существующий FAQ. Убраны принудительно тёмные фон и текст информационных блоков. Тема автоматически следует настройке устройства, как и у остального приложения.

Разделы используют общий компонент PanelPage с прежними панелями внутри. Фон карты сохранён, но текст главной не просвечивает, поскольку её компонентов на этих адресах нет. На мобильной ширине шаги главной идут вертикально, заголовок раздела и возврат переносятся при необходимости.

Длинные ответы полного FAQ больше не ограничены max-height: 384px; открытый ответ растёт по содержимому и не обрезается на телефоне. Для кнопок FAQ добавлена связь aria-controls с ответом.

## Проверки

- Production build и проверка типов успешны. Все 13 существующих frontend тестов прошли.
- Проверено 14 HTTP ответов: главная, все четыре раздела, canonical, sitemap, robots, 404, изображения, CSS, JavaScript и API.
- В HTML каждой страницы раздела один H1, собственный canonical, нет landing-hero, landing-content и role=dialog.
- Все четыре раздела проверены в светлой и тёмной темах на ширинах 1280 и 390 px. Горизонтального переполнения нет, главная и модальные окна отсутствуют.
- Проверены мобильное меню, возврат на главную и возврат браузером; прокрутка после переходов свободна.
- На мобильном FAQ высота длинного первого ответа равна его scrollHeight: 1017 px; текст не обрезан.
- Пересчёт WGS84 → WGS84 на новой странице: вход 56 / 12, выход 56 / 12. API отвечает успешно.
- Журнал проверенной вкладки без ошибок и предупреждений.

Для воспроизводимой проверки обоих вариантов CSS использован отдельный локальный диагностический proxy theme-preview.cjs: он активирует светлые или тёмные media правила готового CSS, не меняя настройки ОС и исходники приложения. Снимки подтверждают разные вычисленные цвета: светлый текст rgb(15,23,42), тёмный rgb(241,245,249). Диагностический proxy остановлен после проверки. На основном локальном адресе действует обычная системная тема.

First Load JS главной уменьшился со 119 до 108 kB, поскольку компоненты разделов загружаются на своих адресах. Это показатели сборки, не измерение Core Web Vitals. Прежние предупреждения кэша Webpack и базы Browserslist сохраняются.

Backend и вычислительные функции не менялись. Полный импорт и скачивание Excel в этой доработке повторно не проверялись; соответствующие исходные тесты пройдены в блоке 1. Проверки контейнеров и публичного сайта остаются этапом выпуска.
