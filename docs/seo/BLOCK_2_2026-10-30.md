# Техническая основа SEO GeoConverter

Блок 2 реализован и проверен локально 30 октября 2026 года в ветке devcodex. Главная получила метаданные для поиска и публикации ссылки, добавлены robots.txt, sitemap.xml и favicon. Изменения не опубликованы на VPS.

## Изменения

| Область | Реализация |
| --- | --- |
| Title | Конвертер координат онлайн — WGS84, МСК, СК-42 \| ГеоКонвертер |
| Description | Перевод координат между WGS84, МСК, СК-42, СК-95, ГСК-2011 и UTM. Пакетная обработка, импорт и экспорт Excel. Выбор системы и зоны. |
| Основной домен | metadataBase: https://geoconverter.ru |
| Canonical главной | https://geoconverter.ru, эквивалент корневого URL с завершающим / |
| Open Graph | website, ru_RU, название и описание сервиса, абсолютные URL главной и PNG 1200×630 |
| Twitter Card | summary_large_image с тем же описанием и изображением |
| Favicon | SVG и ICO 32×32, автоматически подключаются средствами Next.js |
| robots.txt | Разрешён обход сайта; запрещён обход путей /api и /healthz; указана карта сайта |
| sitemap.xml | Единственный опубликованный содержательный URL: https://geoconverter.ru/; без вымышленного lastmod |

Canonical и метаданные главной заданы в app/page.tsx, а общий домен и шаблон заголовков — в app/layout.tsx. Страница 404 не наследует canonical главной. Для новых страниц необходимо задавать собственный canonical и добавлять URL в sitemap после публикации.

Интерактивная часть прежнего app/page.tsx перенесена в components/HomePage.tsx. Сравнение с резервной копией подтвердило полное совпадение содержимого, кроме комментария с путём файла и имени функции. Состояния, обработчики, модальные окна и порядок компонентов сохранены. Новый app/page.tsx содержит метаданные и отрисовывает HomePage.

Новые зависимости не добавлялись. Backend, расчётные функции, элементы конвертера, CSS, инфраструктура и настройки VPS не изменены. Видимый H1 и содержательные блоки относятся к блоку 3.

First Load JS главной остался 119 kB, размер маршрута — 16,2 kB, как в блоке 1. Новая картинка для публикации ссылки не добавлена в видимое содержимое главной.

Сохранились предупреждения, зафиксированные в исходном состоянии: Webpack не может сохранить кэш зависимостей, Browserslist сообщает об устаревшем caniuse-lite. Сборка успешна. Зависимости в рамках SEO задачи не обновлялись.

Backend тесты в этом блоке повторно не запускались: код backend не менялся, 50 тестов прошли в блоке 1. Полный импорт и скачивание XLSX через браузер в этом блоке не повторялись. До публикации остаются проверки контейнеров и публичных ответов после выпуска.
