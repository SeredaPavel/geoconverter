# Подключённые зоны СК-63

Рабочий реестр `app/sk63_registry.py` включает явно разрешённые определения EPSG.
При старте параметры из установленной базы PROJ сверяются с исследовательским
`geoproj_catalog.reference.json`. Поля `runtime_enabled: false` в исследовательском
JSON относятся к исходным записям и кандидатам: выполнение разрешает отдельный
список `APPROVED_EPSG`, а не изменение статуса исследовательского материала.

| Район и зоны | EPSG | Статус API |
| --- | --- | --- |
| A1–A4 | 2935–2938 | ready |
| K2–K4 | 2939–2941 | ready |
| C0–C2 | 3350–3352 | ready |
| X1–X7 | 7825–7831 | ready |

Пример кода: `SK63:EPSG:7828` — район X, зона 4.
В API и интерфейсе X обозначает восточную координату (easting), Y — северную
(northing). Это отличается от букв осей в исходном определении EPSG; pyproj
вызывается с `always_xy=True`. Excel использует тот же порядок X/Y.

Зона определяется выбранной записью, без автоматического извлечения из координат.
Для перехода к проекции ГК используются её существующие настройки зоны.
Поддержаны геодезические системы, ГК и переходы между рабочими записями СК-63.
Наличие конкретной операции перехода зависит от доступных данных PROJ.

## Записи в разработке

Все 103 сочетания районов/зон исходного каталога geoproj сохранены отдельно с
кодами `SK63:GEOPROJ:<вариант>:<зона>` и статусом `dev`. Их соответствие EPSG не
подтверждено; особенно важно не смешивать варианты района C с одинаковыми номерами.
Районы B, H, U, Y дополнительно показаны с пометкой «зоны уточняются».
В интерфейсе недоступные записи видны, подписаны «в разработке» и отключены.
Прямой запрос с таким кодом возвращает 400. МСК имеют отдельный рабочий реестр:
МСК-47, зона 2, подключена; остальные 258 записей имеют `dev`. См. [MSK.md](MSK.md).

Опубликованные кандидаты C/P/T/X не исполняются: требуется проверить соглашения
о смещениях, нумерацию и контрольные точки. Описание источников сохранено в JSON.

## Точность и проверки

Для переходов с СК-63 используется `allow_ballpark=False`, ошибки и бесконечные
результаты отклоняются. Ответ содержит `meta.operations` с описанием реально
использованной операции и её заявленной точностью; неизвестная точность — `null`.
Это не заменяет независимые контрольные точки и проверку области применения,
которая показана в описании каждого доступного пункта интерфейса.

Проверки в `tests/test_sk63_conversion.py`: оси и координаты начала проекции всех
17 зон, прямой/обратный пересчёт, СК-63 ↔ ГК, отклонение dev-кодов, импорт 100 точек,
каталог и ведомость. Запуск из `backend`:

```text
python -B -m unittest discover -s tests -v
```

Источники: база EPSG в PROJ, [структура СК-63 (GIS-Lab, Andrey1)](https://gis-lab.info/qa/sk-63.html),
[исходный каталог geoproj](https://geoproj.ru/). Версии, параметры и дополнительные
источники зафиксированы в исследовательском JSON.
