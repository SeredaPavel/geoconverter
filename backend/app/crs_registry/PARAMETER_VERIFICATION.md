Параметры также сопоставлены с таблицами раздела 2.27 пособия Д. А. Денисова,
2016, опубликованного заповедником «Керженский»:
https://kerzhenskiy.ru/wp-content/uploads/2020/03/gis-metodichka_final.pdf
Проверены печатные страницы 157, 159, 163, 165. Помимо присланных зон подключены
опубликованные МСК-47/1 и МСК-47/3.

В присланных строках отсутствует определение перехода между геодезическими
датумами. `+ellps=krass` задаёт эллипсоид, а не связь с WGS-84. Авторские строки
QGIS дополнительно содержат
`+towgs84=23.57,-140.95,-79.8,0,0.35,0.79,-0.22`.
В рабочем реестре используется именованный Pulkovo 1942 (EPSG:4284),
а тесты проверяют согласованность результата с полной опубликованной строкой.
Параметры перехода не переносятся автоматически на любые другие МСК.

Это подтверждённые опубликованные настройки и согласованная реализация,
**не сертификация официальных ключей перехода**. Для кадастровой/геодезической
точности требуются независимые пункты с известными координатами и точностью.

## Метод проверки

1. Прочитаны авторские определения. Исходные параметры не подгонялись.
2. Для каждой зоны отправлены три искусственные точки на публичную форму
   geoproj.ru (`/geocalc`). Координаты пользователей не использовались.
3. Ответ нормализован: X geoproj = север, Y geoproj = восток;
   API проекта использует x = восток, y = север.
4. Сверен локальный WGS-84 → выбранная СК с `allow_ballpark=False`.
5. Сохранены входные и выходные числа в рабочих JSON, дата и источник.
   Тесты воспроизводятся без интернета. Более ранние три пары МСК-47/2 сохранены.
6. Дополнительно проверены начала проекций, обратные и межзональные переходы,
   новые МСК ↔ СК-63, импорт 100 строк и оба формата XLSX.

Новые контрольные данные содержат 84 пары: 48 для МСК и 36 для каталога СК-63.

## СК-63: результаты поиска и ограничения

Опубликованные параметры X/C/P/T:
С. І. Бурковський и соавторы (2021), DOI 10.30748/zhups.2021.70.08,
https://doi.org/10.30748/zhups.2021.70.08, таблицы 2 и 5.
Определения EPSG из установленной базы PROJ сверены с сохранённым снимком.

- P1–P4: подключены как новые определения на Pulkovo 1942. Положительный
  сдвиг на север из статьи реализован вычитанием (lat_0=0, y_0=-12900.563).
  Знак и зональные восточные смещения подтверждены контрольными парами.
- X1–X6: подтверждено соответствие каталога geoproj EPSG:7825–7830.
- C1–C2: подтверждено соответствие каталога geoproj EPSG:3351–3352.
  Контрольные пары соответствий C и X находятся внутри BBOX определений EPSG.
  Меридиан C1 каталога равен 24.95°, а C1 статьи — 21.95°.
  Определения статьи с таким же номером не подменяют проверенные EPSG.
- C3–C4: проверенные кандидаты статьи не совпали с одноимёнными записями
  geoproj. C3–C6 остаются dev; недостающие параметры не экстраполировались.
- T1–T4: таблица 2 дала расхождение около 375 км с geoproj; таблица 5 статьи
  также противоречит таблице 2 по меридианам T. Записи остаются dev.
  Обе причины не устранялись подгонкой по контрольным координатам.

Контрольные данные отклонённых C3–C4/T1–T4 сохранены в `rejected_candidates`
в `sk63_definitions.json`; загрузчик читает только `definitions`.
Исторические кандидаты в `geoproj_catalog.reference.json` сохранены отдельно.

Существующие 17 определений EPSG сохранены. После дополнения каталог содержит
29 доступных пунктов СК-63 (21 различная проекция, восемь пунктов — соответствия
уже подключённым EPSG) и 95 недоступных пунктов. Для МСК доступны 16 из 259.

## Пределы проверки

Согласие с калькулятором на трёх точках не доказывает сантиметровую точность
и не устанавливает границы зоны. Точки выбирались для проверки формул и осей,
а не как геодезические опорные пункты. Новые неподтверждённые границы/BBOX
не добавлялись. Не определяются автоматически кадастровый вариант системы,
локальная калибровка, высотная система и эпоха координат.

Рабочий сервис не зависит от доступности geoproj и не отправляет туда данные.
