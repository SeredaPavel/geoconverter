## Полезность GeoBridge

[Калькулятор GeoBridge](https://geobridge.ru/proj) загружает публичный каталог
`/proj/api`. Его браузерный код декодирует JSON и передаёт строки PROJ в Proj4js.
Получено 575 записей, включая пользовательские и разные версии определений.
Это полезный источник опубликованных формул, но не официальный реестр СК.
Сам сайт ограничивает назначение приблизительным определением местоположения.

Ключи вида `EPSG:6335000`, `EPSG:633V01` в этом каталоге являются внутренними
обозначениями GeoBridge. Они не импортируются как зарегистрированные EPSG.
В API GeoConverter используются собственные коды, указанные ниже.

Из каталога извлечены ровно нужные опубликованные записи. В рабочих JSON
сохранены исходные строки, идентификаторы записей, SHA-256 полученного каталога
и контрольные пары. Библиотека GeoBridge не включается в рабочий сервис.
Наличие остальных записей в источнике само по себе не включает их в GeoConverter.

## МГГТ Москвы

Код API: `MSK:GEOPROJ:mos:1`.
В интерфейсе: «МСК г. Москва (МГГТ / МСК-77, приближённо)».

Совпадающие определения опубликованы:

- [Александр Фадеев, МГГТ Москвы](https://terraingis.ru/msk-77.html), основной текст;
- [публичный каталог GeoBridge](https://geobridge.ru/proj/api), запись 1717,
  внутренний ключ `EPSG:6335000`.

| Параметр | Значение |
| --- | --- |
| Проекция | Transverse Mercator |
| Начальная широта | 55.66666666667° (55°40′) |
| Осевой меридиан | 37.5° |
| Масштаб | 1 |
| False easting | 16.098 м |
| False northing | 14.512 м |
| Эллипсоид | Bessel 1841 |
| Сдвиги к WGS-84 | 316.151, 78.924, 589.650 м |
| Повороты PROJ `towgs84` | −1.57273, 2.69209, 2.34693 угл. секунды |
| Масштабный параметр перехода | 8.4507 ppm |

Знаки поворотов соответствуют опубликованной строке PROJ, а не порядку знаков
параметров MapInfo. Это важное различие соглашений преобразования.

Определение сохраняется как BoundCRS (`bound_proj4` в реестре), с отдельным
датумом Бесселя и явным переходом к WGS-84. Подстановка Pulkovo 1942 или
преобразование только на основании одинаковых названий запрещены.

Пять искусственных точек (55.75, 37.6), (55.6, 37.3), (55.9, 37.9),
(55.4, 37), (56, 38) проверены через geoproj. Расхождение менее 0.001 м.
Числа также сопоставлены с опубликованной реализацией Proj4js GeoBridge,
выполненной локально на тех же входах. Это проверка реализации формул,
не дополнительный независимый геодезический каталог.

Ранее рассмотренный пример GIS-Lab с x_0=0, y_0=0 отличается примерно на
22 м из-за другого положения начала координат. Он не исправлялся подгонкой:
в новом определении используются опубликованные 16.098 и 14.512 м.
Другие встречающиеся в комментариях локализации и ключи не смешиваются.
Назначение нового варианта — приблизительный пересчёт; официальная локализация
для геодезических/кадастровых работ на всей территории Москвы не подтверждена.

## СК-63, район V

Источники параметров:

- GeoBridge `/proj/api`, точные названия «СК-1963 район V зона 1» … «зона 6»;
- Д. А. Денисов, пособие 2016 года, [печатная страница 173](https://kerzhenskiy.ru/wp-content/uploads/2020/03/gis-metodichka_final.pdf#page=173);
- [публикация dab](https://ecency.com/@dab/sk-63-raion-v).

| Код API | Меридиан | False easting, м | False northing, м |
| --- | --- | --- | --- |
| `SK63:GEOPROJ:V:1` | 49.03333333333° | 1300000 | −9414.70 |
| `SK63:GEOPROJ:V:2` | 52.03333333333° | 2300000 | −9414.70 |
| `SK63:GEOPROJ:V:3` | 55.03333333333° | 3300000 | −9414.70 |
| `SK63:GEOPROJ:V:4` | 58.03333333333° | 4300000 | −9414.70 |
| `SK63:GEOPROJ:V:5` | 61.03333333333° | 5300000 | −9414.70 |
| `SK63:GEOPROJ:V:6` | 64.03333333333° | 6300000 | −9414.70 |

Для всех шести: начальная широта 0°, масштаб 1, эллипсоид Красовского,
базовая СК Pulkovo 1942. Седьмая зона не выводится экстраполяцией.
Для каждой зоны проверены три искусственные точки с широтами 54°, 53.7°,
54.3° и долготами меридиана, меридиана −0.4°, меридиана +0.4°.
Сохранены результаты geoproj и расчёт опубликованной библиотеки GeoBridge.
Расхождения с обоими вариантами менее 0.001 м, допуск тестов — 0.01 м.

V1 не является МСК-63/1 Самарской области: разность северных координат
составляет 5500000 м. Для МСК-16/1 разность равна 5700000 м.
Соответствие осей и эти различия отдельно проверяются тестами.

## Исправления пользовательской таблицы

- МСК-50/1–2, МСК-63/1–2, МСК-16/1–3, МСК-02/1–2, МСК-52/1–3
  уже подключены; параметры совпадают с ранее найденными публикациями.
- Для МСК-47 меридианы зон 1/2/3 — **27.95 / 30.95 / 33.95°**.
  В присланной таблице номера первых двух зон смещены на одну.
  При lat_0=0 северное смещение равно −6211057.628 м.
  Сохранённое рабочее определение зоны 2 использует lat_0=0.1° и −6200000 м;
  нельзя сочетать это смещение с lat_0=0 или с чужим меридианом.
- Для района X при lat_0=0 false northing примерно **−9214.688 м**.
  Положительный знак из таблицы неприменим к этому параметру PROJ.
  Уже подключённые EPSG используют lat_0=5/60° и y_0=0; они сохранены.
- Для МСК-1964 СПб уже работают lon_0=30°, lat_0=0, k=1,
  false easting=95942.17 м, false northing=−6552810 м.

## Почему МСК-78 не объединена с МСК-1964

В опубликованном `transform-proj30.js` GeoBridge пункт
`GB:H:1 МСК - 78 (поправки Санкт-Петербург)` использует отдельную функцию
`transform6478Drv`. Она выбирает поправки по номеру планшета с шагом 2000 м,
а не просто меняет название обычной проекции МСК-1964.
Поиск планшета выполняется отдельно в прямом и обратном направлениях.
Вне записей таблицы точки не добавляются в результат этой функции.

Независимая проверка границ применения, переходов на стыках планшетов,
однозначности обратного пересчёта и соответствия официальной МСК-78 отсутствует.
Поэтому `MSK:GEOBRIDGE:78:1` добавлена как отдельная **dev** запись и
отклоняется API в обоих направлениях, включая пустой список точек.
Псевдоним МСК-78 → МСК-1964 не вводится.

## Проверка и пределы точности

Тесты проверяют контрольные пары, знаки, датум и оси, отрицательные координаты
МГГТ, обратные и межсистемные переходы. Runtime не обращается к GeoBridge или
geoproj и не отправляет им пользовательские координаты.

Согласие формул на контрольных точках не подтверждает сантиметровую точность
или официальность ключей. Региональные деформации и локализации не проверялись;
границы систем не выводились из расположения искусственных точек.

Текущий состав: 17 доступных МСК и 243 dev (259 исходных записей плюс одна
отдельная МСК-78); 35 доступных пунктов СК-63, представляющих 27 различных
проекций, и 89 dev. Новыми здесь являются МГГТ и шесть проекций V.
