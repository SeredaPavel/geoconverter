## Проверка и уточнённые варианты

Каждый кандидат проверялся по полной опубликованной строке, без подбора
коэффициентов по ответам калькулятора. Проверены:

1. Проекция, эллипсоид, метры, оси и явный datum shift.
2. Три точки WGS-84 → региональная СК: центр и две точки со сдвигом
   ±0,3° по широте / ±0,4° по долготе.
3. Согласованность именованной основы Pulkovo 1942 с опубликованным
   семипараметрическим переходом к WGS-84.
4. Обратный пересчёт контрольных пар, начала проекций и межсистемные маршруты.

Из первоначальных 325 кандидатов 314 прошли допуск 0,01 м.
Десять отклонённых записей I/L заменены отдельно опубликованными вариантами:

- **I1–I4:** GitHub N0=−12900,566 м расходится примерно на 0,034 м;
  GeoBridge публикует N0=−12900,60 м. Этот вариант проверен на тех же точках,
  расхождение менее 0,001 м. Самостоятельно смещение не вычислялось.
- **L1–L6:** GitHub округляет меридианы до шести знаков и расходится примерно
  на 0,021 м. В GeoBridge опубликованы 81°31′ + 6°*(n−1) с большей точностью;
  расхождение этого варианта на тех же точках менее 0,001 м.

Максимальное расхождение среди новых подключённых определений — менее
**0,0044 м**. Тестовый допуск 0,01 м не изменялся ради включения кандидата.

Также разрешена часть особых случаев этапа 6:

- **C3–C6:** явные опубликованные записи продолжают нумерацию каталога
  с C1=24,95°, не несовпадающую нумерацию старой статьи с C1=21,95°.
- **T1–T4:** подтверждены опубликованные меридианы 37°59′, 40°59′,
  43°59′, 46°59′. Старые противоречивые кандидаты статьи остаются в истории
  отклонённых вариантов; их наличие не мешает другому проверенному определению.

## Сквозные проверки и пределы результата

Автотесты проверяют все сохранённые контрольные пары и начала проекций,
возвратный расчёт, переходы с каждым семейством ГК, блокировку dev.
Для новой партии добавлены Excel-сценарии на 100 точек: МСК-01, обе ширины
МСК-66, три варианта МСК-72 и МСК-87 за 180-м меридианом.
Оба экспорта проверяются на сохранение количества и координат строк.
Для СК-63 проверяются варианты 3°/6° и обмен с МСК/ГК.

Результат проверки: 42 теста основного набора backend и 3 дополнительных
теста протокола партии прошли; 11 тестов frontend и TypeScript прошли.
Дополнительно проверены HTTP `/api/crs`, отказ всех 8 dev в обоих направлениях,
100 точек МСК-72 (1,5°) → ГК-ГСК-2011 (3°) → МСК и оба HTTP-экспорта XLSX.

Проверка реализации **не подтверждает сантиметровую геодезическую точность**.
Искусственные точки не заменяют контрольные пункты на местности, официальные
ключи локализации и проверку региональных искажений сетей. Точные границы зон
не выводились из расположения точек, BBOX не добавлялись. Ограничения МГГТ
и статического ПЗ-90.02/ПЗ-90.11 сохраняются, см. [GK.md](GK.md).
В рабочем приложении и тестах пересчёт выполняется без обращений к источникам.
