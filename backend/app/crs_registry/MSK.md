# МСК: каталог и локальный пересчёт

Каталог регионов и зон взят с [geoproj.ru](https://geoproj.ru/): 259 записей.
На 23.10.2026 публичная HTML-форма и `js/bundle.js` содержат названия,
идентификаторы и списки зон, но не расчётные определения. Форма отправляет
координаты на серверный `/geocalc`; ответ содержит результат, без параметров СК.
Проект не обращается к этому сервису при пересчёте пользовательских координат.

## Подключённая зона

`MSK:GEOPROJ:47:2` — МСК-47, Ленинградская область, зона 2.
Определение: [Игорь Белов, «Местные системы координат в WKT 2», GIS-Lab](https://gis-lab.info/qa/msk-wkt2.html).
Базовая СК — Pulkovo 1942 (EPSG:4284), метод Transverse Mercator:

| Параметр | Значение |
| --- | --- |
| Начальная широта | 0.1° |
| Осевой меридиан | 30.95° |
| Масштаб | 1 |
| Восточное смещение | 2250000 м |
| Северное смещение | −6200000 м |

Определение создаётся непосредственно из этих параметров. Номер зоны МСК
не используется для автоматического выбора одноимённой зоны EPSG.

Рабочие определения и результаты контрольных запросов хранятся в
`msk_definitions.json`, загрузчик — `../msk_registry.py`. Доступны переходы
к геодезическим СК, ГК и рабочим определениям СК-63 и обратно, а также импорт
100 строк и оба варианта Excel-экспорта. Зона задана выбранной записью;
переключатели автоматической зоны и ширины зоны относятся к проекциям ГК.

В проекте **X — восток, Y — север**. У geoproj.ru для проверенной МСК порядок
обратный: X — север, Y — восток. При сравнении результаты переставлены.

## Проверка и пределы точности

23.10.2026 выполнены три контрольных запроса WGS-84 → МСК-47/2 на geoproj.ru
для искусственных точек (59.95, 30.3), (59.5, 31), (60.5, 32).
Расхождение с локальным pyproj менее 0.003 м. В тестах допуск — 0.01 м.
Это проверка согласованности на трёх точках, а не подтверждение геодезической
точности на всей территории. Фактическая точность перехода зависит от выбранной
PROJ операции; API возвращает её описание и заявленную точность в `meta.operations`.
Приближённые операции ballpark запрещены. Автоматические проверки не используют
сеть или сервер geoproj.ru.

Пример ПМСК Москвы из той же статьи GIS-Lab **не включён**: на трёх контрольных
точках он расходится с вариантом «МСК г.Москва» geoproj.ru примерно на 22 м.
Сходство названия не подтверждает тождественность определений.

## Остальные зоны

258 записей остаются `dev`: интерфейс показывает «в разработке» и отключает выбор;
прямые API-запросы отклоняются даже с пустым списком точек. Для подключения нужны
определение WKT/PROJJSON/PROJ с базовой СК и параметрами перехода либо официальная
спецификация, источник, соглашения об осях и контрольные пары координат.
Для городских СК могут дополнительно понадобиться параметры преобразования на плоскости.
Готовые координаты калькулятора сами по себе не заменяют определения СК.

Запуск проверок из `backend`: `python -B -m unittest discover -s tests -v`.
