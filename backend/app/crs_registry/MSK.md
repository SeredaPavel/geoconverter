# МСК: каталог и локальный пересчёт

Каталог регионов и зон взят с [geoproj.ru](https://geoproj.ru/): 259 записей.
Отдельно добавлена одна недоступная запись МСК-78 (вариант GeoBridge).
Форма и JavaScript содержат названия и идентификаторы, а `/geocalc` возвращает
результаты без расчётных определений. Сервис используется только при исследовании
искусственных контрольных точек. Пересчёт пользовательских координат и тесты
выполняются локально, без обращений к geoproj.

Итого 17 рабочих записей и 243 записи `dev` (включая отдельную МСК-78). Примеры кодов:
`MSK:GEOPROJ:02:1`, `MSK:GEOPROJ:50:2`, `MSK:GEOPROJ:1964:1`.
Нулевой префикс региона в кодах 01–09 сохраняется.

Рабочие параметры и контрольные пары хранятся в `msk_definitions.json`,
загрузчик — `../msk_registry.py`, построение проекций — `../regional_definitions.py`.
В JSON сохранены ссылки, авторы, опубликованные строки PROJ и даты проверки.
Исходные строки сохранены как свидетельство источника; выполнение строит
Transverse Mercator на именованной базовой СК Pulkovo 1942 (EPSG:4284)
для определений на эллипсоиде Красовского. МГГТ сохраняет отдельный датум Бесселя
и явное семипараметрическое преобразование к WGS-84 (`bound_proj4`, BoundCRS).
Подменять его на EPSG:4284 или терять трансформацию нельзя.
`+ellps=krass` без определения датума недостаточно для перехода к WGS-84.
Для проверенных точек выбранная PROJ операция согласуется с опубликованным
семипараметрическим переходом; это отдельно проверяется тестами.

Уже работавшее определение МСК-47/2 сохранено: начальная широта 0.1°, меридиан
30.95°, масштаб 1, восточное смещение 2250000 м, северное −6200000 м.
Опубликованная альтернативная запись с `lat_0=0`, `y_0=-6211057.628` отличается
из-за округления примерно на 0.0024 м по северной координате.

## Оси, зоны и доступные направления

В проекте **X — восток, Y — север** (`always_xy=True`). У geoproj для
проверенных систем обозначения X/Y обратные; контрольные пары нормализованы.
Зона фиксируется выбранным кодом МСК. Переключатели авто-зоны и ширины зоны
относятся только к ГК. Автоматического определения зоны МСК по региону или
ближайшему меридиану нет: фактическое распределение может идти по кадастровым районам.

Доступны переходы между рабочими МСК, географическими СК, ГК и рабочими СК-63,
обратный пересчёт, импорт 100 строк и оба варианта Excel-экспорта.
Недоступные операции PROJ отклоняются, приближённые ballpark запрещены.
`meta.operations` содержит описание и заявленную точность выбранной операции.
`meta.regional_definitions` содержит сведения о выбранных определениях.

## Проверка и ограничения

29.10.2026 для каждой из 16 зон МСК на Pulkovo 1942 получены три независимых от локального расчёта
результата WGS-84 → МСК на geoproj. Сверялись опубликованные параметры без подгонки
по результатам калькулятора. Для новых определений расхождение менее 0.001 м;
для сохранённого варианта МСК-47/2 — менее 0.003 м. Допуск тестов — 0.01 м.
Три более ранние контрольные пары МСК-47/2 также сохранены.

Это проверка согласованности реализаций, **не подтверждение сантиметровой
геодезической точности**. Региональные искажения сетей и официальные ключи
перехода не проверены. Границы зон не восстановлены по расположению контрольных
точек; новые неподтверждённые BBOX не добавлялись.

Для МГГТ Москвы подключён другой опубликованный вариант: меридиан 37.5°,
начальная широта 55°40′, эллипсоид Бесселя, x_0=16.098 м, y_0=14.512 м.
Пять точек сверены с geoproj и опубликованной реализацией GeoBridge;
расхождение менее 0.001 м. В названии и описании отмечена приближённость.
Это не официальная локализация и не гарантия точности на всей территории.

Ранее рассмотренный пример ПМСК Москвы из GIS-Lab с нулевыми смещениями
по-прежнему не подменяет этот вариант: он расходился с geoproj примерно на 22 м.

МСК-78 GeoBridge не является синонимом МСК-1964: это отдельные поправки по
планшетам. Запись `MSK:GEOBRIDGE:78:1` оставлена dev до независимой проверки,
в том числе обратного перехода и границ планшетов. Для остальных 242 записей
каталога geoproj также нужны проверенные определения. Выбор всех dev на фронтенде
отключён, прямые запросы API отклоняются.

Подробности сверки пользовательских строк и СК-63: [PARAMETER_VERIFICATION.md](PARAMETER_VERIFICATION.md).
Проверки из `backend`: `python -B -m unittest discover -s tests -v`.

Дополнение по GeoBridge, МГГТ, МСК-78 и исправлениям таблицы: [GEOBRIDGE_VERIFICATION.md](GEOBRIDGE_VERIFICATION.md).
